Connect Staff Phones via Shop Wi-Fi

Use your smartphone or tablet as an untethered wireless barcode scanner or cashier terminal over the local Wi-Fi router. No internet required!
Open on Phones Connected to Shop Wi-Fi:
http://{{ local_ip }}:8000
Open Google Chrome on Android or Safari on iPhone and type this exact address.

Quick 3-Step Setup for Staff Phones:

  1. Ensure the phone is connected to the same Wi-Fi router as this computer.
  2. Open Chrome / Safari and type http://{{ local_ip }}:8000.
  3. Install as App (PWA): Tap the three dots (⋮) in Chrome and select "Add to Home screen" (or "Install app"). An app icon will appear on your phone home screen!

Windows Firewall Notification

When you start the application for the first time, Windows Defender Firewall may display a pop-up alert saying:

"Windows Defender Firewall has blocked some features of this app"

What to click:

  • Check the box for "Private networks, such as my home or work network".
  • Click the "Allow access" button.

This allows other devices on the shop's local Wi-Fi to reach the register while keeping out unauthorized public connections.
