How to Schedule Nightly Automated Backups in Windows Task Scheduler

  1. Press Win + R, type taskschd.msc, and hit Enter to open Windows Task Scheduler.
  2. In the right panel, click Create Basic Task...
  3. Name it: Liquor Shop Nightly Backup and click Next.
  4. Trigger: Select Daily, click Next, and set the time to 11:45 PM (after shop closing).
  5. Action: Select Start a program, click Next.
  6. Program/script: Click Browse and select backup.bat located in your install folder (e.g. C:\Program Files\LiquorShop\backup.bat).
  7. Click Next and then Finish.

Every night at 11:45 PM, Windows will run this script automatically without opening any interfering windows.
